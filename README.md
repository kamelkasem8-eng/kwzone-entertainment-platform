# KwZone - Entertainment & Events Platform

An interactive web application designed to feature entertainment deals, events, and activities in Kuwait.

## Features
- Interactive dashboard for entertainment offers.
- User-friendly interface for browsing venues and activities.
- Multi-language toggle support (Arabic/English).
- Partner/Admin portal integration.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** Vercel / GitHub Pages
